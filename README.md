# Map Jigsaw

Interactive geographic jigsaws: drag boundary areas into place, explore statistics, and test yourself in quiz mode.

- **England**: 90 areas from ONS 2023 boundary data
- **USA**: 50 states + DC from US Census 2020 data

Everything runs in the browser. Originally built on Manus; moved to a standalone site in November 2026.

## Develop
```
npm install
npm run dev      # local dev server
npm run check    # type-check
npm run build    # production build into dist/
```
Pushing to `main` publishes the site to GitHub Pages automatically.
